# 검증 근거와 해석 범위

이 문서 묶음은 2026-10-10에 작성했다. 현재 소스의 기준 커밋은 `88d20039f594d1b4fedc79e5fd5412317885ad92`다. 이번 문서 작성에서는 앱 동작을 변경하지 않았다.

## 근거의 종류

| 근거 | 확인할 수 있는 것 | 확인할 수 없는 것 |
|---|---|---|
| 사용자 신고·확인 | 보인 문제와 사용자가 선택한 기준 | 신고만으로 모든 내부 원인 확정 |
| 실제 계정의 저장 로그·화면 대조 | 당시 특정 작업의 접수·입력·조회 결과 | 다른 버전·계정·미래 작업의 성공 |
| 저장 화면 재판독 | 같은 이미지의 글자·좌표·선택 규칙 비교 | 현재 실제 화면이나 서버 결과 |
| 가상 SDK·프로세스·시계 | 실패·취소·경쟁의 반복 재현과 코드 경계 | 실제 서버의 모든 정책·지연 |
| 실제 Tk·WPF의 합성 화면 | 배치·초안·복사·스크롤과 해당 조건의 UI 시간 | 실계정 연결과 모든 모니터 배율 |
| 컴파일·내장 런타임 검사 | 필요한 입력으로 빌드하고 리소스를 검증 | 사용자 기기의 로그인·발송 성공 |

과거 검사 개수는 당시 범위를 보여 준다. 서로 다른 시점의 개수를 합쳐 ‘현재 전체 검사 통과 수’로 표시하지 않는다. 회귀 검사가 통과한 뒤 실제 오류가 나온 사례도 남긴다.

공개 소스 검증의 Spoiler 빌드는 `-SkipTests`로 컴파일·런타임을 확인했다. 같은 시점의 전체 WPF 회귀 검사를 다시 수행한 것은 아니다. 선정 Python 검사는 가상 자료와 개인 자료가 없는 소스 사본에서 수행했다. 임시 폴더를 OneDrive 밖에 두고 최종 확인했다. 앞선 파일 교체 오류의 원인을 OneDrive로 확정하지는 않는다.

로컬 원본을 적은 행은 **공개 저장소에서 내려받을 수 있는 파일 링크가 아니다.** 개인정보가 있는 자료의 위치와 집계 근거를 설명한다. 이전 보고서의 `exports/` 링크도 같은 한계가 있다. 공개 검사는 가상 자료로 계약을 확인하며 실계정 사고 전체를 공개 재생하는 도구는 아니다.

## 중요한 상태 구분

| 표현 | 뜻 |
|---|---|
| 직접 전송 성공 | 검증된 서버 접수 응답 확보. 상대방 단말의 수신·읽음과 다름 |
| 예약 acknowledged | 새 접수 완료 알림 확인. 재등록 차단 |
| 예약 verified | 저장 상세의 대상·시각·전체 본문 일치. 미래 실제 발송·수신은 미확인 |
| unknown | 외부 제출·전송 가능성이 있고 결과를 확정하지 못함. 자동 재시도 금지 |
| 미시도·제출 전 중단 | 외부 동작을 시작하지 않았다는 근거가 있음. 조건 수정 후 재개 가능 |
| 예약 슬롯 해제 | 시각 경과에 따른 여유 추정. 발송 증거나 재등록 허가가 아님 |
| 방 옆의 N개 | Spoiler의 로컬 보관 메시지 수. 서버 안읽음 수가 아님 |

## 공개하지 않은 원본

계정 이메일·비밀번호·토큰, 실제 대화명·방 ID, 학생·보호자 명단, 메시지 원문·예약 CSV, 실계정 화면·발송 로그는 올리지 않는다. 삭제하지 않고 로컬에 보존한다.

개인 이름 교정은 [빈 예시 manifest](../../native_schedule_recipient_samples.example.json)만 공개한다. 실제 원본 이미지와 manifest가 없으면 전용 자료 검사는 건너뛰고 일반 OCR 경로를 사용한다. 다른 픽셀에서 예상 이름을 강제로 반환하거나 비슷한 이름으로 치환하는 기능은 아니다.

## 현재 남은 한계

- 서버 직접 예약 등록은 미구현이다. 화면 자동 등록과 구분해야 한다.
- 예약에는 로그인된 Windows 데스크톱과 인식 가능한 카카오톡 UI가 필요하다. 잠금·다른 팝업·버전 변경은 중단 사유다.
- 카운터는 같은 로컬 기록을 쓰는 Hub·CLI의 추정치다. 다른 기기의 수동 변경과 서버 지연은 반영하지 못한다.
- Spoiler는 전체 최신 1,000개·최대 7일을 보관한다. 기간 전체 수집이나 모든 과거 대화 복구를 보장하지 않는다.
- 수신·열람에 읽음 명령을 연결하지 않는다. 다른 기기와 답장 후 상대방 표시까지 통제하는 보장은 아니다.
- 비공식 통신은 외부 프로토콜 변경과 인증 상태의 영향을 받는다. 모든 계정에서 계속 동작한다는 보장은 없다.
- AI 답장, 기간별 CSV 추출, 결석·보강 분류와 로컬 타이머 예약은 현재 완료 기능이 아니다.
- 앱 필수 파일 복구와 잃은 모든 파일·이전 Git 이력 복구는 다르다.

새 시험 결과나 실패가 나오면 해당 사례와 이 표를 함께 갱신한다. 과거 성공 수치를 현재 상태처럼 덮어쓰지 않는다.
